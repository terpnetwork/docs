Use a **self-custody** wallet to hold keys, sign txs, and talk to Terp Network (`morocco-1` mainnet, `90u-4` testnet).

<Callout type="info" title="Wallet landscape">
**Keplr** is the primary browser-extension guide here. **Ledger** covers hardware keys. Programmable auth (safewords, message filters, composites) lives under [Authenticators](/docs/guides/authentication/authenticators) — not a browser wallet product page.
</Callout>

## Quick chain params

| | Mainnet | Testnet |
|---|---------|---------|
| Chain ID | `morocco-1` | `90u-4` |
| Prefix | `terp` | `terp` |
| Fee denom | `uthiol` | `uthiolx` (confirm live) |
| Coin type | 118 (Cosmos) / check wallet UI | same |
| RPC | `https://rpc.cosmos.directory/terpnetwork` | public testnet RPC |
