REST API for bank, staking, wasm, gov, and other module queries.

## Default public endpoint

```text
https://api.terp.network
```

## Common calls

```bash
## Bank balances
curl -s "https://api.terp.network/cosmos/bank/v1beta1/balances/terp1..." | jq .

## Bank params
curl -s "https://api.terp.network/cosmos/bank/v1beta1/params" | jq .

## Wasm code info
curl -s "https://api.terp.network/cosmwasm/wasm/v1/code/1" | jq .
```

## Enable on your node

`app.toml`:

```toml
[api]
enable = true
address = "tcp://0.0.0.0:1317"
```
